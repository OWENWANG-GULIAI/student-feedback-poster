# 隐私与证据

学员反馈是“真实证据”，不是可自由改写的营销文案。保留聊天内容原意、气泡和必要上下文；只裁切无关区域、做版式缩放，或遮挡明确的敏感信息。

## 默认遮挡

默认遮挡学员昵称、头像、手机号、微信号、地址和其他可识别身份信息。用户明确授权公开某一项时才可保留。聊天正文中出现联系方式或身份线索时同样遮挡。

对“AI授权讲师班”，用户已确认截图中的“AIGC企业应用实战讲师授权班”是同一项目的完整群名，可作为原始证据保留；其他项目不得套用此规则。

## 打码坐标

渲染脚本用来源截图像素坐标接收遮挡区域：`[x, y, width, height]`。在执行前先查看截图并逐项列出要遮挡的区域；若无法可靠定位，停止正式出图并请求用户标注或提供已处理截图。

```bash
--redactions '[[35, 210, 95, 95], [145, 225, 180, 54]]'
```

第一个矩形可以遮挡头像，第二个矩形可以遮挡同一条消息的昵称。必须按实际截图调整，不能复制示例坐标。

## 不可接受的处理

- 用 AI 重绘聊天截图、头像、Logo 或二维码。
- 为了画面完整而补写、删改或曲解学员评价。
- 未检查隐私区域就输出可公开发布的海报。
- 将原始聊天截图拷贝进项目包、公开仓库或演示样本。
